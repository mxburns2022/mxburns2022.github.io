## 🚀 Get Started in 3 Steps

### Step 1: Install
```bash
cd /home/matt/Documents/development/personal/mxburns2022.github.io
bundle install
```

### Step 2: Run
```bash
bundle exec jekyll serve
```
Then visit `http://localhost:4000`

### Step 3: Customize
Edit `_config.yml` with your information:
```yaml
title: "Your Name"
github_username: your-github-username
google_scholar: "your-scholar-id"
linkedin_username: your-linkedin-id
```

## 🌐 Deploy to GitHub Pages

1. Create repository: `username.github.io` on GitHub
2. Push code:
   ```bash
   git add .
   git commit -m "Initial research website"
   git branch -M main
   git remote add origin https://github.com/username/username.github.io.git
   git push -u origin main
   ```
3. Your site is live at `https://username.github.io`

## 💡 Tips

- **Dates Matter**: Publications and posts are sorted by date. Use YYYY-MM-DD format.
- **File Names**: Use kebab-case (my-great-paper.md) for file names.
- **Excerpts**: Write good 1-2 sentence excerpts for previews.
- **Links**: Update social links in _config.yml to customize footer.
- **Images**: Put images in `assets/images/` and reference in content.
- **Tags**: Use consistent tags across publications/posts.
